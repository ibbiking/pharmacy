# 8) Short invoice/return numbers, FBR invoicing preference, split sale-tax
#    breakdown on receipts, and per-business currency selection
#
# What changed:
# - invoice_no is now short (INV-000123) and return_no is RET-000123,
#   instead of long timestamp-based numbers. No manual step needed —
#   existing rows are untouched, only new sales/returns get the new format.
# - Businesses can opt into "FBR Invoice" numbering in Business Settings
#   (defaults to "Local Invoice" — nothing changes unless an owner opts in).
#   The actual FBR API call is a documented placeholder — see
#   App\Services\FbrInvoiceService — do not enable in production until
#   that's replaced with the business's real FBR API contract.
# - Purchases now attribute a split, disclosure-only tax breakdown ("GST"
#   from the Paid Unit Cost Price markup + any named Sale Taxes configured
#   on the purchase) onto each sale's InvoiceItem, shown split-by-name on
#   the sale receipt, the return receipt, and the Invoice show page.
# - Businesses can now pick a Currency in Business Settings; its symbol is
#   used everywhere a price already showed a currency symbol (dashboard,
#   products, purchases, sales). A business can also add its own custom
#   currency (visible only to that business) via Currencies > Add Currency.

# Run the new migrations:
php artisan migrate
